One connection model

Log in to a Host once. Everything else rides along.

Hosts own SSH credentials. Terminals, file browsers and database connections tunneled “via Host” reuse the same session. Production is red everywhere, confirms destructive statements by parsing, not regex, and can be locked read-only.

API workbench

Test the API, not just call it.

Load tests, mock servers and contract checks run on your machine, with no cloud quota, no account and nothing to upload.

Files · coding CLIs

Open a folder. Start an agent. Watch what it changes.

The Files tab is a keyboard-driven, git-aware file manager, and every folder, on your machine or a server, is one click from Claude Code, Codex CLI, Gemini CLI, Aider or OpenCode.

Code here

Pick a CLI from the Code menu and it opens in a coding layout: the folder's files on the left, the agent on the right, in your own shell with your own login. Installed versions show in the menu. On a Host it runs on the server, over the session you already have.

See every edit live

Folders refresh on their own. Changed files carry M, A, ? and D badges, the footer shows the branch, and one toggle narrows the list to what changed. The agent's tab has Changes for a git diff stat beside it.

A real file explorer

One pane with Quick access, pinned folders and servers on the side, and the right-click menu you expect: cut, copy, paste, rename, duplicate, properties. Text and images open in the app, the rest in their own apps. Search finds files in every subfolder as you type, through fsearch on macOS or Everything on Windows when you have them.

Agents side by side

Start each run in a new git worktree with its own branch, so Claude Code and Codex can work on the same repository at once. The Activity pane lists every agent as working, waiting or exited, and tells you when one needs you.

Scratchpad · notes

Paste it now. Find it after a restart.

Ctrl+Shift+N (⌘⇧N) opens a Notepad-style scratchpad for the query you are holding onto, a log excerpt or a hostname. It keeps everything until you close it, and turns into a small local Obsidian when a note is worth keeping.

Scratch notes that stay

Every scratch note is written as you type, so quitting or a crash loses nothing. It is there next time until you close it, and closing one with text asks first. Press the shortcut again for a fresh page.

Plain markdown files

Ctrl+S names a scratch note and saves it as a .md file in Switchyard's notes folder, on your machine only. Saved notes save their own edits, and the folder opens in Obsidian or any editor.

Read, search and link

Search every note by name and text. Read mode renders headings, lists, tables and code, and [[wiki links]] open the note they name, or create it.

Ten engines, one dialect layer.

Every SQL engine sits behind the same Driver / Dialect traits, so quoting, LIMIT vs TOP vs FETCH FIRST and script splitting are engine-aware everywhere.
