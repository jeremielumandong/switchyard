Switchyard
Features GitHub

Databases, terminals and file transfer.
One connection model.

A fast, native desktop app for PostgreSQL, SQL Server, MySQL, Oracle, SQLite and more, with SSH terminals, tunnels, SFTP and FTP. It visualizes query plans, finds hotspots, and lets coding CLIs optimize queries through a read-only MCP server.

Features

Many engines

PostgreSQL, SQL Server, MySQL/MariaDB, Oracle, Snowflake, Cloudflare D1, SQLite, MongoDB and Redis.

Hosts and tunnels

One SSH session per Host, shared by terminals, file browsers and tunneled database connections.

File transfer

SFTP, FTP and FTPS, plus S3, R2 and Azure Blob as file systems.

Query plans

PostgreSQL and SQL Server plans in one view, with findings and index suggestions.

Coding CLIs

Claude Code, Codex CLI and Gemini CLI plan and optimize queries through a read-only MCP server.

Streaming results

Rows appear as they arrive; the grid scrolls a million rows without dropping frames.

Safe by default

Secrets in the OS keychain, strict host keys, and Production connections that confirm destructive statements.

Native and fast

Written in Rust on GPUI. Runs on macOS, Windows and Linux.
